# Objects

One job: route a cold agent to repository nouns that matter for change impact.

## Inputs

| Source | File/Location | Section/Scope | Why |
|---|---|---|---|
| Object index | _index.md | Full file | Cluster and status routing |
| Schema | ../_meta/schema.md | Full file | Card semantics |
| Object template | ../_templates/object.md | Full file | Card shape |

## Process

1. Find the noun cluster.
2. Open only the relevant card.
3. Follow the See source into the subject tree.
4. Treat stub cards as routing hints, not authority.

## Outputs

| Artifact | Location | Format |
|---|---|---|
| Object card | cluster/[slug].md | Markdown |
