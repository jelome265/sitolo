# Sitolo — Qwen Agent Adapter

Sitolo uses the Interpretable Context Methodology (ICM) as its repository workflow. This file is an agent-specific bootstrap adapter, not an alternative source of project truth.

## Mandatory routing

1. Read the root `CLAUDE.md` first.
2. For organizational work, follow `workspaces/CLAUDE.md` and select the smallest bounded primary workspace.
3. Read the selected workspace `CLAUDE.md` and `CONTEXT.md` before acting.
4. Follow the selected ICM stage `CONTEXT.md`, then only the L3 references it explicitly routes.
5. Treat generated stage outputs as working artifacts, not authoritative project truth.
6. Do not classify work as Engineering merely because it involves code, a repository, infrastructure, or implementation.
7. Do not invent requirements, departments, routes, authorities, or missing context. Surface ambiguity at the applicable router.

## Authority

`CLAUDE.md`, workspace routers, and stage `CONTEXT.md` files are routing/control surfaces. Canonical product, commercial, compliance, security, and technical truth remains in the authoritative documents they route to.

Do not copy or reinterpret the contents of `CLAUDE.md` here. If this adapter conflicts with the canonical ICM routing, the canonical routing wins and this adapter must be corrected.

## Workflow integrity

Respect mandatory audit, remediation, verification, security, human-check, and handoff gates defined by the selected workspace and stage. A green CI result is evidence, not permission to bypass an explicitly required semantic audit or verification stage.
