## Migration policy

The current repository still contains the original files under `docs/`. This grouping index is intentionally non-destructive. A future physical move may be performed as a separate controlled change after all inbound links, automation references, implementation instructions and agent contracts have been verified.

## Authority rule

Grouping is navigation, not authority. The canonical authority for a concept remains the document designated by the commercial corpus audit and precision/consistency contract. A document must not silently redefine a metric, tier, price, segment, experiment, regulatory boundary or commercial decision owned elsewhere.
