# Sitolo Engineering Review Skill

Use this bundled skill during audit-oriented stages.

Trace each material claim to:

requirement → implementation → test or evidence

Check tenant and branch isolation, authorization, transaction boundaries, idempotency, concurrency, offline authority, external failure, auditability, observability, migrations, and resource bounds when applicable.

Do not infer compliance from naming. A test is evidence only when it exercises the claimed control.

Return evidence-backed findings with exact file or test references where possible. Separate fact, inference, unresolved decision, and proposed remediation.
