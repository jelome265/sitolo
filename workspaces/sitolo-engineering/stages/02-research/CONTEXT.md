# 02 Research

One job: establish whether current external evidence is required and, when required, produce it.

## Inputs

| Source | File/Location | Section/Scope | Why |
|---|---|---|---|
| Run brief | ../01-select/output/ | Selected run brief | Defines the research question |
| Context policy | ../../shared/context-loading.md | Full file | Loading discipline |
| Research guide | references/research-evidence.md | Full file | Evidence rules |

## Process

1. State the exact claim or decision that may require external evidence.
2. Decide whether repository evidence is sufficient.
3. If external evidence is required, search authoritative current sources for the relevant jurisdiction, provider, standard, version, or date.
4. Record source, date/version, authority level, claim, implication, and uncertainty.
5. If external research is not required, record that conclusion and the evidence supporting it.
6. Separate documented fact from inference and recommendation.
7. Write the research memo to output/.
8. If research changes scope, return to 01-select for an edited brief.

## Human Check

Review the evidence decision, sources, and unresolved questions. Edit the memo before investigation.
