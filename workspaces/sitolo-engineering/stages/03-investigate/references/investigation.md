# Investigation Reference

Inspect, when applicable:

- crate/module ownership and dependency direction;
- domain invariants and state transitions;
- authorization and tenant/branch scope;
- persistence and migrations;
- tests and security negative cases;
- outbox/jobs and idempotency;
- external adapters;
- observability;
- performance/resource bounds.

Trace claims to real code or tests. Names and comments are not evidence of enforcement.
